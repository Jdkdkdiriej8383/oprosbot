# 🗳 OprosBot — Telegram-бот интерактивных опросов с поддержкой тем форума (Topics)

Полнофункциональный асинхронный Telegram-бот на **Python 3.11+** и **aiogram 3.x** для создания и проведения опросов со **скрытыми промежуточными результатами**, полноценной поддержкой **форумных тем супергрупп (Topics / `message_thread_id`)** и **открытых текстовых ответов**.

🔗 **Целевой репозиторий проекта:** [https://github.com/Jdkdkdiriej8383/oprosbot.git](https://github.com/Jdkdkdiriej8383/oprosbot.git)

---

## 🌟 Ключевой функционал

### 1. Поддержка форумных тем (Telegram Topics / `message_thread_id`)
- **Автоопределение контекста**: если команда `/create_poll` вызвана внутри темы форума группы, бот автоматически считывает текущий `message_thread_id` и целевой `chat_id`.
- **Публикация из ЛС**: при создании опроса в личных сообщениях с ботом мастер предлагает выбрать:
  - Опубликовать в текущем диалоге (ЛС).
  - Опубликовать в конкретную группу и тему форума (по ID `chat_id:topic_id`, ссылке на тему или пересылке сообщения из нужной ветки).
  - Опубликовать через Inline-режим (`@bot poll_id`).
- **Публикация результатов в ветку**: при завершении опроса (по таймеру или вручную) исходное сообщение в теме обновляется (кнопки отключаются), а в эту же ветку (`message_thread_id`) публикуется финальный пост с диаграммой!

### 2. Типы опросов
1. **Опрос с выбором вариантов (Inline-голосование)**:
   - Интерактивные кнопки под сообщением в чате/теме.
   - **Скрытие результатов во время голосования**: участники не видят проценты и количество голосов до закрытия опроса, что исключает эффект толпы. При нажатии на кнопку выводится персональный pop-up (alert): *«Ваш голос учтен: «Вариант 1»»*.
   - **Возможность переголосовать**: участник может изменить голос до окончания опроса.
   - **1 человек = 1 голос**: гарантируется уникальным ограничением на уровне базы данных.
2. **Опрос с открытым текстовым ответом**:
   - В чат/ветку отправляется карточка вопроса с кнопкой «Ответить».
   - Кнопка ведёт по deep-link ссылке в ЛС бота (`t.me/<bot_username>?start=poll_<id>`).
   - В ЛС через FSM бот принимает развёрнутый текст (до 3000 символов), сохраняет его и позволяет обновить ответ до завершения опроса.

### 3. Завершение опроса и публикация итогов
- **Автоматически по таймеру (дедлайн)**: планировщик **APScheduler** закрывает опрос в указанный срок (15м, 1ч, 6ч, 24ч, 3 дня или произвольное время в минутах/часах).
- **Вручную создателем или администратором чата**: доступна кнопка «Завершить опрос» в панели управления или команда `/close_poll <ID>`.
- **Красивая инфографика**: для опросов с вариантами строится прогресс-бар:
  ```text
  🏁 Результаты опроса (Опрос завершён)

  ❓ Вопрос:
  «Какой фреймворк вы используете для микросервисов?»
  ────────────────────
  FastAPI
  🟩🟩🟩🟩🟩⬜⬜⬜ 60.0% (12 голосов)

  aiogram
  🟩🟩🟩⬜⬜⬜⬜⬜ 30.0% (6 голосов)

  Django
  🟩⬜⬜⬜⬜⬜⬜⬜ 10.0% (2 голоса)
  ────────────────────
  👥 Всего голосов: 20
  🔒 Завершён: 05.11.2026 22:30 UTC
  ```
- **Экспорт для автора**: по текстовым опросам автор получает в ЛС готовые файлы **Excel CSV** (в кодировке UTF-8-SIG с поддержкой кириллицы) и форматированный **TXT**.

### 4. Безопасность и разграничение прав
- Управлять опросом, просматривать промежуточную статистику и закрывать его разрешено **только создателю опроса или администраторам целевой группы**.

## 🛠 Стек технологий

- **Язык**: Python 3.11+
- **Фреймворк**: aiogram 3.x
- **База данных**: SQLite (через `aiosqlite`) или PostgreSQL через `SQLAlchemy 2.0 async`
- **Планировщик задач**: `APScheduler` (`AsyncIOScheduler`)
- **Конфигурация**: `pydantic-settings` / `python-dotenv`
- **Контейнеризация**: Docker, Docker Compose

## 📖 Подробное руководство по настройке

### 1. Как получить токен в @BotFather
1. Откройте в Telegram диалог с [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите отображаемое имя бота (например, `Interactive Polls Bot`).
4. Введите юзернейм бота, заканчивающийся на `bot` (например, `my_interactive_opros_bot`).
5. Скопируйте полученный API токен (вида `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`).
6. **(Рекомендуется) Включите Inline Mode**:
   - Отправьте команду `/setinline`.
   - Выберите вашего бота.
   - Введите текст-плейсхолдер (например, `Поиск опроса...`).
7. **(Для работы в группах)**:
   - В BotFather выберите `/setprivacy` -> выберите вашего бота -> выберите `Disable` (чтобы бот мог видеть команды в группах).
   - Либо просто сделайте бота администратором группы.

---

### 2. Как узнать ID чата и `message_thread_id` темы в Telegram

#### Способ 1: Прямо через самого бота (самый простой)
1. Добавьте созданного бота в группу с темами.
2. В нужной теме напишите команду `/create_poll` — бот **автоматически считает** и `chat_id`, и `message_thread_id` текущей ветки!
3. Либо в ЛС бота на шаге выбора места перешлите любое сообщение из нужной темы форума — бот сам извлечёт ID чата и ветки.

#### Способ 2: Через ссылку на сообщение в теме (Telegram Desktop / Web)
1. В теме форума кликните правой кнопкой мыши по любому сообщению и нажмите **«Копировать ссылку на сообщение»** (Copy Message Link).
2. Ссылка имеет вид:
   `https://t.me/c/1987654321/42/105`
   - `1987654321` — это ID супергруппы. Для API Telegram добавьте спереди `-100`: `-1001987654321`.
   - `42` — это и есть **ID темы форума (`message_thread_id`)**!
   - `105` — ID конкретного сообщения.

## 🚀 Запуск проекта

### Вариант А: Локальный запуск через виртуальное окружение (venv)

```bash
# 1. Клонирование репозитория
git clone https://github.com/Jdkdkdiriej8383/oprosbot.git
cd oprosbot

# 2. Создание и активация виртуального окружения
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

# 3. Установка зависимостей
pip install --upgrade pip
pip install -r requirements.txt

# 4. Настройка файла .env
cp .env.example .env
```

Отредактируйте файл `.env`:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
DATABASE_URL=sqlite+aiosqlite:///oprosbot.db
TIMEZONE=UTC
LOG_LEVEL=INFO
```

Запуск бота:
```bash
python bot.py
```

---

### Вариант Б: Запуск в Docker / Docker Compose

Убедитесь, что установлены `docker` и `docker compose`.

1. Создайте `.env` файл и укажите токен:
   ```bash
   cp .env.example .env
   ```
2. Запустите контейнер в фоновом режиме:
   ```bash
   docker compose up -d --build
   ```
3. Просмотр логов:
   ```bash
   docker compose logs -f oprosbot
   ```
4. Остановка:
   ```bash
   docker compose down
   ```

*Данные базы данных сохраняются в локальной директории `./data` благодаря монтированию тома.*
